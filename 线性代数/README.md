# 线性代数

本目录整理线性代数课程的学习资料，共收录 33 个 PDF，分为笔记、课后题、邱砖习题和历年期中资料四类。

| 子目录 | 内容 | 数量 |
| --- | --- | ---: |
| `笔记` | 按知识主题整理的手写章节笔记 | 7 |
| `课后题` | 教材第一章至第八章的课后题及补充题目 | 9 |
| `邱砖习题` | “邱砖”第一章至后续章节的强化习题整理 | 6 |
| `历年期中` | 2021-2024 年线性代数 B 期中试题、统考试题及手写解答 | 11 |

## 笔记内容

章节笔记主要包括：

- 线性方程组与初等变换
- 行列式
- 矩阵的运算
- 矩阵的相消与相抵
- 二次型与正定
- 线性空间
- 线性映射

## 使用说明

部分资料为扫描版或手写版，文件名保留了原始下载名称，以便和来源对应。历年试题可能同时包含题目与手写解答，使用时请结合当前课程大纲和任课教师要求。

资料仅供课程学习、复习和交流参考。
