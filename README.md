# Personal Course Materials

这是一个用于整理个人课程资料、课程作业和项目文件的 GitHub 仓库。仓库内容主要来自本科阶段的课程学习，方便自己后续查阅，也希望能够为正在学习相关课程的同学提供一些参考。

## 仓库内容

目前仓库包含以下课程资料和作业：

| 目录 | 内容简介 |
| --- | --- |
| `计算概论B` | 计算概论 B 课程相关资料、作业或实验文件 |
| `人工智能与计算思维` | 三次平时作业与 CBDB 数据分析大作业 |
| `高等数学` | 高等数学课程笔记、作业、历年试卷与模拟题 |
| `线性代数` | 线性代数课程笔记、课后题、邱砖习题和历年期中资料 |
| `中级微观经济学` | 中微课程讲义，涵盖消费者、生产者和市场理论等主题 |
| `深度学习中的高效计算方法` | 课程课件、作业与实验要求、实验提交包 |
| `概率论与数理统计` | 概率论与数理统计课程笔记和知识要点 |
| `Applied-Time-Series-Analysis` | 应用时间序列分析课程笔记和作业 |

其中，`Applied-Time-Series-Analysis` 目录目前包含课程笔记和两次课程作业：

- 应用时间序列分析课程作业 1
- 应用时间序列分析课程作业 2

此外，仓库还整理了以下课程资料：

- [高等数学](高等数学/README.md)：分为笔记、作业、试卷与模拟题三个部分。

- [深度学习中的高效计算方法](深度学习中的高效计算方法/README.md)：课件、作业要求和实验成果。

## 使用说明

仓库中的文件主要用于课程学习和交流参考。不同课程、教师和学期的要求可能存在差异，使用时请结合自己的课程要求进行理解和修改，不建议直接照搬提交。

部分作业以压缩包形式保存，以尽量保留原始文件结构；下载后可以解压查看其中的代码、数据、报告或其他附件。
