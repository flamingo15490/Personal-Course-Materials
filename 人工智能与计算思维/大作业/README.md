# 人工智能与计算思维大作业

项目主题：中国历代人物传记数据库（CBDB）数据分析。

## 文件

- `人工智能与计算思维_CBDB大作业.zip`：精简后的完整项目包。

压缩包包含项目说明、作业要求、数据化说明、分析脚本、A-F 各任务成果、维度表、图表和交互式可视化页面，共 212 个文件。

为控制仓库体积，压缩包不包含：

- 约 550 MB 的 CBDB 原始 SQLite 数据库；
- Python `__pycache__` 和 `.pyc` 缓存；
- 旧版 `0/` 目录；
- 临时修补脚本和重复构建脚本。

如需重新运行数据构建流程，请从 [CBDB 官网](https://projects.iq.harvard.edu/cbdb) 获取对应版本数据库，并按压缩包内 README 的说明放入 `latest/` 目录。
