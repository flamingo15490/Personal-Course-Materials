## 数据来源与处理

### 轨迹提取逻辑
1. **地址经历表** `fact_person_address`：提取籍贯、出生地、迁住地、游历地、葬地等 15 类地址事件
2. **任官驻地表** `fact_person_posting`：提取任官期间的驻地信息，标记为"任官驻地"事件类型
3. 两张表纵向合并，按人物+年份排序
4. 去除相邻重复坐标点（距离 < 0.01 度视为同一地点）

### 事件类型分布
游历或曾经到过 (100) > 前住地 (49) > 任官驻地 (31) > 籍贯 (8) > 迁住地 (8) > 祖籍 (5) > 死所 (5) > 出生地 (3) > 葬地 (3)，另有避兵、卜居、流放等少量事件。

### 坐标处理
- 坐标缺失的记录（lat/lon 为空或 0）已剔除
- 岳飛年份数据中存在异常值（min_year=5），系原始数据录入问题，未做修正

## 文件清单

| 文件 | 内容 | 说明 |
|------|------|------|
| `migration_trajectory_data.csv` | 轨迹明细数据 | 218 行，每行一个时空事件点 |
| `migration_summary.csv` | 人物摘要统计 | 8 行，每人一行含轨迹数、年份范围、坐标范围 |
| `migration_map.html` | 交互式迁移地图 | Folium 生成，可缩放、点击查看详情、按人物开关图层 |
| `migration_map_static.png` | 静态迁移总图 | Matplotlib 生成，8 人轨迹合在一张图上，星号=起点，方块=终点 |
| `migration_by_dynasty.png` | 按朝代分组图 | 唐/宋/明 三个子图，便于同朝代内对比 |

## 轨迹数据字段说明

| 字段 | 含义 |
|------|------|
| `c_personid` | 人物 ID（CBDB 主键） |
| `event_type` | 事件类型（出生地、前住地、游历、任官驻地等） |
| `year` | 事件年份 |
| `place_name` | 地名（中文） |
| `lon` | 经度（WGS84） |
| `lat` | 纬度（WGS84） |
| `c_name_chn` | 人物中文姓名 |
| `dynasty_chn` | 所属朝代 |

## 使用方式
- 交互地图：用浏览器打开 `migration_map.html`，左上角可按人物勾选/取消图层
- 点击任意轨迹点可查看人物、年份、地点、事件类型

## 生成脚本
`scripts/c_migration_map.py`，一键运行可复现全部数据提取、地图生成与图表输出。
